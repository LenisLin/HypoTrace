# Dispatch: STOmicsDB Round 2B Bundle Worker

This is the single-bundle assignment wrapper. It is not the stage protocol.

## Required Assignment

Provide a fully instantiated YAML object with no unresolved placeholders:

```yaml
dispatch_generation_id:
assignment_id:
attempt_number:
bundle_id:
bundle_type:
owner_type:
owner_id:
repository_workdir:
nas_data_root:
bundle_staging_directory:
canonical_bundle_directory:
approved_queue_row:
expected_target_paths:
  -
assigned_conda_environment:
```

All filesystem paths are absolute except `expected_target_paths`, whose entries
are NAS-data-root-relative acquisition-plan target paths. The worker resolves
them against `nas_data_root`. The coordinator must pre-create a unique bundle
staging directory before dispatch. `assigned_conda_environment` must name
an existing host conda environment or conda prefix; the worker must not install
packages or create environments.
`expected_target_paths` is generated by the coordinator from acquisition-plan
`target_path` values under the approved bundle target prefix. It verifies
expected physical files only and is not a persistent coverage mapping.

## Required Response

Repeat `dispatch_generation_id`, `assignment_id`, and `attempt_number` exactly
as assigned. Return one staged bundle generation with absolute staged paths and
proposed NAS-root-relative manifest paths using this response contract:

```yaml
dispatch_generation_id:
assignment_id:
attempt_number:
bundle_id:
owner_type:
owner_id:
worker_status:
staged_generation_id:
staged_paths:
publication_proposal:
validation_receipts:
human_review_request:
```

`worker_status` is `LOCALIZED | BLOCKED_EXTERNAL | awaiting_environment`.
For `awaiting_environment`, `staged_generation_id`, `staged_paths`, and
`publication_proposal` are null because no `localization.yaml` is published;
`validation_receipts` records the format and environment error.
`human_review_request` is null unless the assignment itself is contradictory
and requires coordinator resolution.

## Boundary

Handle only the assigned bundle. Do not write registries or canonical paths.
Do not reconstruct TSV coverage, create case IDs, assign `DATA_READY`, write
HVUs, create dual-chain artifacts, install dependencies, or return findings in
place of a terminal bundle package.
