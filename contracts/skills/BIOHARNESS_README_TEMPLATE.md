# Bioharness README Template

This template is only for Condition C.

Document:

- Which bioharness is available.
- How to start or connect to it.
- Which commands, APIs, or interfaces are available.
- How analysis outputs should be saved as artifacts.
- How the final submission must still follow the shared HypoTrace format.

Do not include:

- Hidden references.
- Scoring rubrics.
- Task-specific answer hints.
- Automatic generation of `scientific_chain.jsonl`.
- Automatic generation of `execution_subchains.jsonl`.

The bioharness may support execution. The agent remains responsible for the
HypoTrace submission.
