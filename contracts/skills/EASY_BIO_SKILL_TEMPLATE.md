# Easy Bio Skill Template

This template is only for Condition B.

Allowed content:

- Single-cell analysis method categories.
- Spatial transcriptomics method categories.
- Common method names.
- Documentation or GitHub link placeholders.
- Common pitfalls.
- Best-practice checklist items.

Disallowed content:

- Executable wrappers.
- Automatic state validators.
- Prebuilt pipelines.
- Task-specific answer hints.
- Hidden reference chains.
- Scoring rubrics.

Condition B still uses the same shared output contract from
`contracts/HYPO_TRACE_SKILL.md` and `contracts/output_template/` as all other
conditions.
