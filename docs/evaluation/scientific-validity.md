# Scientific Validity

HypoTrace evaluates scientific analysis quality. It should apply consistent
standards regardless of which model or harness produced the trace.

## Core Rules

- Separate computational observations from biological conclusions.
- Bind every substantive claim to scientific units, execution subchains, and artifacts.
- State uncertainty and scope.
- Treat publication-derived references as anchors, not ground truth.
- Distinguish exploratory analysis from confirmatory analysis.
- Prefer evidence vectors over unsupported categorical labels.

## Bias Controls

HypoTrace should make common analysis biases visible:

- confirmation bias: selecting only supporting results.
- HARKing: presenting post-hoc interpretations as prior hypotheses.
- selective reporting: omitting failed or contradictory analyses.
- subgroup fishing: using uncorrected subgroup findings as central claims.
- observer bias: interpreting ambiguous outputs according to expectation.

## Statistical Controls

Evaluation should penalize:

- treating non-significance as proof of no effect.
- treating statistical significance as biological importance.
- ignoring multiple comparisons.
- omitting effect sizes or uncertainty where relevant.
- extrapolating beyond the data range.
- fitting complex models without validation or adequate sample size.

## Overclaim Examples

- Association described as causation.
- Single-cohort association described as a validated clinical biomarker.
- Ligand-receptor enrichment described as proven physical communication.
- Marker expression described as definitive cell identity.
- Publication claim treated as automatic truth despite inconsistent reanalysis.

## Evidence Quality

Evidence confidence should reflect design quality, measurement quality,
statistical rigor, consistency, indirectness, precision, and publication-derived
uncertainty. Higher-level evidence is not automatically stronger if the method is
poorly executed, and lower-level evidence can be informative when multiple lines
converge.
