# GBM Hypoxia-TAM Public Demo Review Notes

This file points reviewers to the human-readable analysis logic chain and records the public-demo boundary. The full gold/reference material is intentionally included here for demonstration and should not be treated as hidden benchmark material.

## Review Targets

- `analysis_logic_chain.md`: human-readable chain review.
- `analysis_logic_chain.jsonl`: machine-readable analysis chain.
- `reference_scientific_chain.json`, `reference_claim_surface.json`, `reference_execution_chain.json`: HypoTrace reference draft exports.
- `curation_notes.md`: curation boundary, data readiness notes, and promotion checklist.

## Boundary

This public demo exposes gold/reference material to show the extraction result. Real HypoTrace benchmark tasks should keep reference chains, curation notes, truth files, and grading material in NAS or evaluator-only storage.
